エマミルについて（開発目標と目的）

「エマミル」は、「エマージェンシー」と「見る」を合わせた造語であり、「緊急時に見る」という意図を持たせています。

開発の背景と目標

  • 自然災害が多く、将来的に大きい災害が来ると予想されるため、プログラミング等を使って支援することを目的としています。
  • ターゲット：旅行や出張で土地勘のわからない人が、災害時に混み合うネットを介さずに避難場所・避難経路をスマホ等で簡単に確認できるようにすることを目指しています。

アプリの役割と他アプリとの差別化

現在地(GPS)、または入力した住所から最も近い指定避難所を探索し、避難経路を画像として保存します。

  • 写真として端末に保存できる：ネットにつながらなくても簡単に見直せるため、災害時や通信環境の悪い場所で便利です。
  • 印刷・共有が容易：A4サイズとして出力されるため、紙に印刷して共有することも可能です。

アクセシビリティ（誰でも簡単に活用できるように）

  • デザインはシンプルに設計しています。
  • Webアプリ（safariやgoogleなどのブラウザを通して使えるアプリ）として提供し、利用者の環境に依存させません。
  • PWA（ブラウザ画面でなく普通のアプリのように全画面で表示できるようにする仕組み）を使用して、ネイティブアプリのように振る舞う設計です。

免責事項・注意事項

本アプリをご利用の際は、以下のシステム上の制約および注意事項を必ずご確認ください。

1. 住所検索機能に関する注意事項

入力した住所からの探索に使用している「国土地理院 住所検索API」は、名称に国土地理院とありますが、実態は東京大学空間情報科学研究センター(CSIS)が提供するものです。これは実験のための提供であり、予告なしで中止される可能性があります

2. 経路探索とAPI依存について

本アプリはREST API（データや機能をやり取りする窓口）を使用して様々な情報を外部から取得しています。出発地・到着地の緯度・経度から避難場所までの「経路・移動距離・所要時間」を取得する「OpenRouteService Directions API」は、本アプリ使用API群において唯一、利用者にAPIキーの取得・設定が求められます。

3. 情報の確実性について

保存する画像には避難経路が記された地図、移動距離、避難先の名称、出発地、予想所要時間などの情報が表記されますが、これらは平時のデータに基づき自動計算された目安です。実際の災害発生時は、最新の自治体の情報や現地の状況を最優先に行動してください。

4. ブラウザに保存されたAPIキーの取り扱い方について

「OpenRouteService Directions API」のAPIキーは平文でブラウザ上に保存しており、特にフリーデスクなどでは悪用される危険性がありますためアプリを閉じる前に必ず削除してください。

また、本アプリは無料でインターネット上にサイトを公開できる「Github Pages」を使用して運用されています。通信環境やAPIの状況によりサービスが利用できない場合の損害について、開発者は責任を負いかねます。

使用API一覧および提供元情報

エマミルは以下のデータおよびライブラリを使用し、各提供元の規約を遵守して構築されています。

OpenStreetMap Tile API

地理空間情報の巨大なデータベースであり、LeafletなどのJavaScriptライブラリを使用してWebサイトに地図を埋め込むために使用しています。

引用: OSM利用入門 https://openstreetmap.jp/node/762/

Geolocation API

携帯電話の基地局などの地理空間データを使用して、位置情報を取得できるWeb標準APIです[cite: 9]。現在地からの探索時の緯度・経度を取得します。

引用: Google Maps platform https://developers.google.com/maps/documentation/geolocation/overview?hl=ja

国土地理院 住所検索API (CSIS)

日本語で記述された住所・地名・駅名・公共施設名を経度・緯度に変換します。

引用: 「CSISシンプルジオコーディング実験」 https://geocode.csis.u-tokyo.ac.jp/home/simple-geocoding/
zenn記事: https://zenn.dev/ohsun/articles/313bfe4b976274

指定緊急避難場所・指定避難所がすぐわかるAPI

緯度・経度・探索半径・災害の種類を指定するだけで、周囲の避難場所・避難所を取得できます。

API提供: 東海大学宇津研究室「指定緊急避難場所・指定避難所がすぐわかる API」 https://note.com/utuken_tokai/n/n00d035c90ecl
データ提供: 国土地理院「指定緊急避難場所・緊急避難所データ」 https://www.gsi.go.jp/bousaichiri/hinanbasho.html

OpenRouteService Directions API

経路・移動距離・所要時間を取得するAPIです[cite: 9]。経路は等時線で取得できます。

引用: Open RouteSerice https://openrouteservice.org/

Leaflet (Leaflet.js) / html2canvas

Leafletは動的な地図をウェブサイト上に埋め込めるオープンソースライブラリです。html2canvasはDOM要素をブラウザ上で解析し、canvas要素に再構築（画像化）するために使用しています。

引用: Leafletjs https://ja.wikipedia.org/wiki/Leaflet
引用: html2canvas https://easegis.jp/blog/html2canvas/
